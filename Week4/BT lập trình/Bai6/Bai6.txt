- Đoạn code gốc bị sai ở vòng lặp while:
    while (j > 0 && value < arr[j])
- Nguyên nhân:
 Do kiểm tra (j > 0), vòng lặp sẽ dừng ngay khi j = 0.
 -> Thuật toán bỏ qua việc so sánh và chèn phần tử nhỏ nhất vào vị trí đầu tiên của mảng (chỉ số 0).
- Đổi điều kiện (j > 0) thành (j >= 0):
    while (j >= 0 && value < arr[j])

import java.util.*;

public class Solution {
    public static void insertionSort(int[] A) {
        for (int i = 1; i < A.length; i++) {
            int value = A[i];
            int j = i - 1;
            
            // Sửa j > 0 thành j >= 0
            while (j >= 0 && A[j] > value) {
                A[j + 1] = A[j];
                j = j - 1;
            }
            A[j + 1] = value;
        }
        
        for (int num : A) {
            System.out.print(num + " ");
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] ar = new int[n];
        for (int i = 0; i < n; i++) {
            ar[i] = in.nextInt();
        }
        insertionSort(ar);
    }
}
